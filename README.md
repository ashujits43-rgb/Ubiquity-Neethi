# Ubiquity Neethi

Responsive website for Ubiquity Neethi, built with Next.js, React and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

## Deploying to Vercel

Import this repository into Vercel. The project uses standard Next.js build commands and requires no custom build or output-directory configuration.
